Frequently Asked Questions

Everything you need to know about RoleGuard's zero-cloud architecture.

How do I know my IAM policies aren't being sent to a remote server?

RoleGuard is constructed as a self-contained single-file HTML document. You can open your browser's Developer Tools (Network Tab), run scans, and verify that 0 outbound network requests are made. You can also disconnect your internet entirely and run the tool off-grid.

What AWS IAM vulnerability paths does RoleGuard audit?

RoleGuard checks over 21 known IAM privilege escalation paths including iam:PassRole combined with ec2:RunInstances or Lambda execution, wildcard resource permissions (*), policy attachment rights, and missing condition statements.

How do updates work for a zero-cloud HTML tool?

When you purchase a license, you receive access to the release repository. Whenever new IAM escalation vectors or detection rules are added, you can download the updated standalone HTML bundle.
